# 三国杀 · 星河

一个非商业的三国杀同人实现，目标是让朋友之间不氪金也能完整对局。支持单机、局域网联机、手机扫码加入和内置自动更新。

**作者**：星河一叶Roxy  
**维护邮箱**：ck_xuv@vip.qq.com

## 当前进度

- 标准包 108 张牌，42 名武将（标准包 25 名 + 风火林山精选 17 名）
- 5–8 人身份场，主公 / 忠臣 / 反贼 / 内奸；自定义模式支持 2–8 人
- 完整回合流程：判定、摸牌、出牌、弃牌、濒死求桃、身份胜负结算
- 全部标准锦囊、延时锦囊、装备、坐骑
- 武将技能触发系统：视为技、锁定技、主公技、主动技、觉醒技、拼点、翻面、不屈
- 单机人机对局、武将详情、武将图鉴
- 桌面端局域网联机：房主建房，朋友输入地址与房间码加入；断线后由电脑接管
- 手机/平板通过浏览器扫码加入，与电脑同局对战，不需要安装 App
- 自动更新：通过 jsDelivr / ghfast / ghproxy 等镜像读取更新清单，校验 SHA-256 后自动替换程序并重启

## 运行

```bash
npm install

# 浏览器开发
npm run dev

# 桌面端开发（Tauri）
npm run desktop

# 便携版 exe（自动更新使用这一版）
npm run desktop:build:portable

# 生成便携包和更新清单
npm run release:portable -- RainxButterfly/sgs "更新说明"

# 可选的 NSIS 安装包（需要能访问 GitHub 工具链和签名密钥）
npm run desktop:build
```

桌面端首次运行会在本地启动一个 WebSocket 房间服务。若 Windows 弹出防火墙提示，请允许“专用网络”访问，否则朋友的设备无法连接。

## 联机方式

### 桌面局域网

1. 房主打开「局域网联机 → 创建房间」。
2. 把「房主地址」和「房间码」发给朋友，或让朋友直接用手机扫大厅里的二维码。
3. 朋友打开「局域网联机 → 加入房间」，输入地址、房间码和名字。
4. 房主选择模式、人数和自定义规则，空位由电脑补足，点击开始。

### 手机 / 平板

房主电脑创建房间后，大厅会显示二维码与 `http://房主IP:端口/?room=房间码`。手机和电脑连接同一个 WiFi，用相机扫码，浏览器会自动打开联机页并预填房间码，输入昵称即可加入。

- 手机端通过电脑房主托管网页，不需要安装 APK。
- 如果打不开，尝试大厅里列出的其他网卡地址；虚拟网卡通常不能被其他设备访问。
- 跨网络（不在一起的朋友）目前仍建议先用 ZeroTier、Radmin VPN 等组成虚拟局域网。

### 自定义对局

单机「开始游戏」或联机大厅里都可以选择「自定义对局」，可调整：

- 初始手牌、摸牌数、体力上限调整、手牌上限调整
- 身份是否公开、武将技能是否启用
- 是否启用延时锦囊、无懈可击、装备牌
- 2–8 人；2 人为主公/反贼，3–4 人为主公/忠臣/反贼，5 人以上使用标准身份配置

联机时由房主设置，规则实时同步给其他玩家。

## 自动更新

应用会通过多个镜像读取仓库根目录的 `latest-portable.json`，发现新版本后从 jsDelivr / ghfast / ghproxy 等地址下载便携更新包，校验 SHA-256 后自动替换 `sanguosha.exe` 与 `WebView2Loader.dll` 并重启。不需要卸载旧版本，也不需要官方服务器。

发布流程见 [docs/RELEASE.md](docs/RELEASE.md)。仓库地址：[RainxButterfly/sgs](https://github.com/RainxButterfly/sgs)。

注意：

- 请把程序解压到桌面、文档等**可写目录**，不要放在 `Program Files`，否则自动替换可能失败。
- 新版便携包位于仓库的 `updates/` 目录；朋友首次安装下载最新的 `sanguosha-xinghe-win64-<版本>.zip` 即可。
- 更新清单与更新包都在同一个公开仓库里，并由镜像分发；如果仓库或镜像不可信，仍有被篡改的风险。
- NSIS 安装包与官方 updater 签名配置保留在项目里，作为可选分发方式；当前自动更新界面使用的是便携版自更新。

## 技术栈

- React 19 + TypeScript + Vite
- Zustand 状态管理
- 纯 TypeScript 权威引擎，房主进程负责全部结算
- Tauri 2 + Rust WebSocket 房间服务，同时托管移动端网页
- reqwest + SHA-256 便携版自更新；NSIS 安装包与 minisign 签名配置可选
- 客户端只接收脱敏后的状态：不能看到其他玩家的手牌、牌堆和未公开身份

## 规则范围

当前规则以标准包与风火林山精选武将为准，部分复杂结算做了工程化简化，后续会继续校准。
