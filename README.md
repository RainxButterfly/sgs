# 四国闪 · 星河

四国闪桌面对战程序。标准包 + 军争篇 160 张牌，57 名武将，可以单机，也可以和朋友在局域网或手机上一起玩。

## 下载

Windows 安装版：

https://ghfast.top/https://raw.githubusercontent.com/RainxButterfly/sgs/main/updates/siguoshan-xinghe-0.5.3-setup.exe

运行安装程序，按提示安装，桌面和开始菜单会生成快捷方式。

Windows 便携版：

https://cdn.jsdelivr.net/gh/RainxButterfly/sgs@main/updates/siguoshan-xinghe-win64-0.5.3.zip

解压后双击 `四国闪.bat` 启动。

## 内容

- 标准包 + 军争篇 160 张牌，57 名武将（标准包 25 名 + 风火林山 32 名）
- 军争篇：酒、火杀、雷杀、火攻、铁索连环、兵粮寸断、藤甲、白银狮子、古锭刀、朱雀羽扇、骅骝
- 属性伤害与铁索传导、酒增伤、兵粮判定、藤甲/白银等装备效果
- 身份场、1v1、斗地主、国战、自定义对局
- 判定、出牌响应、濒死求桃、身份与阵营胜负结算
- 视为技、锁定技、主公技、主动技、限定技、觉醒、拼点、翻面、不屈、屯田、化身、蛊惑
- 鼠标悬停查看武将技能，点击打开侧边详情，不遮挡牌桌中央
- 中央展示区显示出牌顺序、使用者、目标、弃牌、火攻展示和判定牌
- 右键打开游戏菜单，弹窗可以收起查看牌桌，判定区支持悬停说明
- 联机大厅选将、武将详情、武将图鉴、人机对局
- 局域网联机，断线后由电脑接管；误退可以从主菜单回归，刷新或重开后可用原昵称重新加入
- 手机浏览器扫码加入，支持添加到主屏幕
- 进入对局后再选择武将；主公先亮将，其他武将等所有人选完再亮出
- 设置面板支持对局背景替换和遮罩调节
- 电脑和手机使用两套独立对局布局，手机版针对触屏重新排布

## 联机

房主打开「局域网联机 → 创建房间」，把界面上的地址和房间码发给朋友；朋友在「加入房间」里填写。

房主选好模式与人数后点击「开始选将」，所有人在对局前从自己的三名候选武将里选择，选择结果会实时显示在座次列表里，房主再进入对局。

手机和电脑连接同一个 WiFi，扫描大厅里的二维码，输入昵称即可加入。手机端会自动切换到独立的触屏布局，横向滑动查看其他角色，点击手牌出牌。

不在同一网络时，可以先用 ZeroTier、Radmin VPN 等工具组成虚拟局域网，再填写房主的虚拟地址；也可以在路由器上把房主端口转发到本机后填写公网地址。

首次创建房间时如果 Windows 弹出防火墙提示，请允许「专用网络」访问。

手机打开房间地址后，可以用浏览器的「添加到主屏幕」把对局页固定到桌面。

## 自定义

单机和联机大厅都可以选择「自定义对局」，可以调整初始手牌、摸牌数、体力上限、手牌上限、身份是否公开、武将技能、延时锦囊、无懈可击、装备牌和人数。

「军争篇」开关在单机设置和联机大厅里，可以单独关闭 52 张军争牌。

## 背景

游戏内右上角「设置」可以更换桌面图片，并调节遮罩深度。图片会压缩后保存在本机，不会上传。

## 模式

- 身份场：5–8 人，主公/忠臣/反贼/内奸
- 1v1：2 人单挑，双方没有身份，也没有主公体力加成
- 斗地主：3 人，地主对两名农民
- 国战：4–8 人，按魏、蜀、吴、群阵营团战，存活到最后的势力获胜
- 自定义：2–8 人，可调整手牌、摸牌、体力、身份、技能与牌堆范围

## 自动更新

程序会读取仓库中的 `latest-portable.json`，从 jsDelivr、ghfast、ghproxy 等地址下载更新包，校验后替换程序并重启。

建议把程序解压到桌面、文档等可写目录，不要放在 `Program Files`。

发布步骤见 [docs/RELEASE.md](docs/RELEASE.md)。

## 开发

```bash
npm install
npm run dev
npm run desktop
npm run desktop:build:portable
```

构建桌面版需要 Rust、Tauri 和 WebView2。安卓原生包需要 Android SDK、NDK 与 JDK 17，步骤见 [docs/ANDROID.md](docs/ANDROID.md)。
